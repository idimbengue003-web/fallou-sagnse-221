## Déploiement sur Vercel

1. Connectez-vous sur https://vercel.com avec votre compte GitHub.
2. **Add New → Project**.
3. Importez ce dépôt (`fallou-sagnse-221`).
4. Framework Preset : **Other** (site statique) — aucun build, aucun output directory.
5. Cliquez **Deploy**.

Le site est en ligne en quelques secondes.
