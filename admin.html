Connexion à l'admin

Pour modifier le site, il faut un jeton d'accès GitHub. Le dépôt est public, mais l'édition (sauvegarde + upload de photos) nécessite un jeton personnel.

  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. Generate new token (classic) → cochez la case repo → générez.
  3. Copiez le jeton (il commence par ghp_) et collez-le ci-dessous.

Le jeton reste stocké dans votre navigateur (localStorage) et n'est envoyé qu'à l'API GitHub (api.github.com). Il ne quitte jamais votre machine.

Modifiez les champs ci-dessous puis cliquez « Enregistrer » (en haut). Le site se met à jour tout seul en ~1–2 min (GitHub Pages + régénération automatique).
